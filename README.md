# My Hero App

A simple and elegant hero showcase application built with modern frontend technologies. The project displays a collection of heroes with their images and details in a clean UI. The website is fully responsive and deployed on Netlify.

## 🧾 Overview

My Hero App is a frontend-based hero listing website. It presents a set of heroes with images and basic information. The UI is clean, minimal, and responsive. The goal of this project is to practice frontend development skills, data rendering, and responsive layout building.

---

## 🛠️ Technology Stack

* **HTML5**
* **CSS3** (Flexbox / Grid)
* **JavaScript (ES6)**
* **Netlify** (Deployment)

---

## ⭐ Features

* Clean and responsive UI
* Displays a list of heroes with images
* Hover effects & card-based layout
* Fast and lightweight static site
* Deployed and accessible globally via Netlify

## 🖥️ Run Locally

To run this Vite + React project locally, follow these steps:

1. **Clone the repository:**

```
git clone <your-repo-url>
```

2. **Navigate to the project folder:**

```
cd your-project-folder
```

3. **Install dependencies:**

```
npm install
```

This will install Vite, React types, ESLint, DaisyUI, and all other devDependencies.

4. **Start the development server:**

```
npm run dev
```

5. **Open in browser:**
   Vite will show a local link, usually:

```
http://localhost:5173/
```

Open it in your browser to view the project.
